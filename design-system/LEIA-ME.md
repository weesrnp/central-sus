# TI Saúde · Sistema de Design HS

Padrão reutilizável de marca e interface de Weslei Neves · TI / Departamento de Saúde de Honório Serpa/PR. Versão 1.0.0, 02/11/2026.

Abra **manual-visual.html** para consultar o manual e experimentar os perfis. A demonstração funciona sem internet e usa dados fictícios. O documento de referência é **DESIGN.md**.

**EXEMPLOS.md** organiza as pranchas PNG de cores com códigos, tipografia e interfaces. **VALIDACAO.md** resume os testes do kit. Os arquivos de cores reutilizáveis são **tokens.css** e **tokens.json**.

Para um projeto novo:

1. Copie esta pasta para `design-system/` do projeto.
2. Preencha **NOVO-PROJETO.md** e salve a ficha como DESIGN local.
3. Forneça **PROMPT-PARA-IA.md** e a pasta à IA que vai implementar.
4. Use os tokens e componentes como base; implemente o comportamento no ambiente do projeto.

O padrão reúne as quatro referências originais e a revisão visual aprovada do Acompanha HS 1.4.1. Preserva Imuniza (Outfit/Inter), Acompanha (Jakarta/índigo) e HS-APS (Jakarta/navy), com Jakarta e azul institucional como ponto de partida de sistemas novos.

As pastas de aplicações e os quatro arquivos de entrada foram preservados. Este pacote contém a consolidação; sua criação não aplica mudanças aos sistemas.
