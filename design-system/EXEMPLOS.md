# Exemplos e pranchas visuais

Abra `manual-visual.html` para ler as diretrizes com exemplos, ou `exemplo-interface.html` para experimentar somente a interface. Ambos funcionam localmente, sem internet, com arquivos da mesma pasta. Mantenha a estrutura ao copiar.

## Cores com códigos

- [Base institucional](assets/paleta-base.png)
- [Imuniza HS](assets/paleta-imuniza.png)
- [Acompanha HS](assets/paleta-acompanha.png)

Cada prancha mostra cor, código hexadecimal, papel e nome do token. No manual, trocar o perfil/tema atualiza os valores. A prancha Base também representa a rampa do HS-APS.
